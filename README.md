# مجلس | Majlis

صالة ألعاب عربية للشبكات المحلية. تضم جاكارو لأربعة أو ستة لاعبين، وأونو لا ترحم من لاعبين إلى ستة على طاولة فردية. يستضيف هاتف أندرويد أو حاسوب الطاولة وتفتح الأجهزة الأخرى رابط الدعوة في متصفحاتها على الشبكة نفسها.

## تشغيل المضيف على الحاسوب

يتطلب المشروع Node.js 22.12 أو أحدث. من مجلد المشروع شغّل:

```sh
npm ci
npm run build
npm start
```

افتح العنوان الذي يظهر في الطرفية. اتصلوا بالشبكة نفسها، أنشئ طاولة وشارك رابطها. اجعل المنفذ 8787 متاحًا على الشبكة المحلية الخاصة.

## المشروع

- `src/` واجهة React العربية للصالة والدعوات ولوح جاكارو وطاولة أونو.
- `src/styles/` نقطة دخول واحدة للتنسيقات، مع ملفات مستقلة للصالة والطاولات والنوافذ والمكوّنات المشتركة.
- `public/` الصور والخطوط ومكتبتا توليد وقراءة رمز الدعوة.
- `dist/` ناتج Vite الذي يقدّمه مضيف الحاسوب ويُضمّن في تطبيق Android.
- `core/` وحدات JavaScript مشتركة لقواعد اللعب وإدارة الغرف. يستوردها مضيف Node.js مباشرة، ويبنيها Vite لحزمة محرك مستقلة داخل WebView في أندرويد.
- `android/` مضيف اللعبة للهاتف.
- [تقرير التقدم](docs/PROGRESS.md)

## اللعب من الهاتف

1. ثبّت [أحدث حزمة أندرويد](https://github.com/ameenalqershi/majlis-royal/raw/refs/heads/main/downloads/majlis-latest.apk) على هاتف المضيف. فعّل نقطة اتصال الهاتف ووصل أجهزة الضيوف بها، أو صِل جميع الأجهزة بشبكة واي فاي واحدة.
2. افتح **مجلس** على المضيف واختر **العب أونو** أو **العب جاكارو**. اكتب اسمك وحدّد عدد المقاعد. يظهر رمز QR ورابط دعوة الطاولة. إذا ظهرت عدة عناوين، اختر عنوان شبكة اللاعبين. يمكن أيضًا فتح عنوان المضيف في المتصفح وإدخال رمز الطاولة.
3. يمسح كل ضيف الرمز بكاميرا هاتفه ويفتح رابط الطاولة ويكتب اسمه. يتيح زر **مسح رمز الدعوة** في شاشة الانضمام استخدام كاميرا التطبيق أو اختيار صورة الرمز. بعد اكتمال المقاعد يضغط المضيف **بدء المباراة**.
4. في أونو، اضغط الورقة التي تريد لعبها، واختر اللون أو اللاعب عند الحاجة ثم أكّد. يظهر السحب والروليت ونداء أونو بحسب حالة الطاولة.
5. في جاكارو، اختر ورقة ثم الحركة. تضيء الأحجار المعنية ويُحدّد موضع الوصول بحلقة ذهبية متقطعة. يمكنك لمس الحجر لتحديد حركة تخصّه، ثم الضغط على **تأكيد الحركة**.

أبقِ التطبيق مفتوحًا على المضيف. تحفظ نافذة اللاعب هويّة المقعد عند تحديث الصفحة. تبقى حالة المباراة في ذاكرة المضيف وتنتهي بإغلاقه. يحتاج التشغيل إلى متصفح حديث أو Android System WebView محدّث. عند استخدام شبكة ضيوف تعزل الأجهزة عن بعضها، استخدم نقطة اتصال تسمح باتصال الأجهزة بالمضيف.

## البناء والتحقق

- للتطوير، شغّل `npm start` وفي طرفية ثانية `npm run dev`. يمرّر Vite طلبات اللعب إلى المضيف على المنفذ 8787.
- لبناء APK تجريبي موقّع محليًا، شغّل `npm ci` ثم `npm run android` مع JDK وAndroid SDK Platform 35 وBuild Tools 35.0.0. يمكن تحديد مجلد SDK عبر `ANDROID_HOME`. الناتج `build/android/majlis.apk`. لا تُرفع مفاتيح التوقيع إلى المستودع.
- قبل نشر إصدار مستقر، أضف الحزمة الموقّعة إلى [مجلد التنزيلات](downloads/) باسم `majlis-<version>.apk`، وانسخ الملف نفسه إلى `majlis-latest.apk`. ارفع الملفين إلى `main` قبل إنشاء وسم الإصدار، وأرفق الحزمة المرقّمة بالإصدار. يتحقق GitHub Actions من تطابقها مع ملفَي التنزيل.
- اختبارات المحرك والغرف: `node --test test/*.test.mjs`.
- اختبار الواجهة: شغّل المضيف، ثم نفّذ `CHROME=/path/to/chromium node scripts/check-ui.mjs`. تكتب الأداة لقطات العرض في `build/previews`.
- يشغّل GitHub Actions اختبارات المحرك والواجهة، ويبني APK ويختبر تثبيته وفتح الصالة واستضافة اللعبتين على محاكي Android 15. يمكن تشغيل فحص Android محليًا بعد البناء بالأمر `node scripts/check-android.mjs` مع جهاز اختبار أو محاكي متصل عبر `adb`.
